Cookie Policy

This Cookie Policy describes the current version of brain. based on the code shipped in this build.

Cookies used by brain.

None. The current build does not create or read browser cookies through document.cookie, and it does not load an analytics, advertising, marketing, authentication, payment, maps, video, or social widget that would add a third-party cookie.

Browser storage used by brain.

The site uses localStorage for the app's core functionality. It stores your memories, collections, reflections, reminder fields, and theme preference locally in your browser. localStorage is not a cookie, but some privacy and electronic-communications laws can regulate similar storage or access technologies separately.

Do you need to consent to cookies?

There is no cookie-consent banner in this build because there are no non-essential cookies or tracking technologies to consent to. The localStorage usage is tied to the core functionality of the browser-only app. Whether a separate notice or consent requirement applies to localStorage or similar technologies in a particular jurisdiction should be confirmed before launch.

Third parties

This build has no third-party script, embed, analytics provider, advertising network, payment provider, authentication provider, map, social widget, or externally hosted font. If any of those are added later, this policy should be updated and any required consent flow should be implemented before launch.

Contact

Privacy/legal contact is not configured yet.

Before launch, set LEGAL_CONTACT_EMAIL in the main app to the address you want users to use for privacy and legal questions.

Legal note

This policy is product documentation, not legal advice. Requirements differ by jurisdiction and should be reviewed before launch.
